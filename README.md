## Cara Menjalankan
1. Clone repository
2. Buka di IntelliJ IDEA
3. Jalankan `SmartApplication.java`
4. Akses `http://localhost:8080`

## Teknologi
- Java 26
- Spring Boot 4.1.0
- PostgreSQL (Supabase)
- JWT Authentication
- Railway (Deploy)
